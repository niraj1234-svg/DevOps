# Linux – DevOps Practical Tasks

This directory contains six Linux administration and DevOps practical assignments completed during my DevOps learning journey.

## Practical Tasks

| Task | Topic | Description |
|---|---|---|
| 01 | User & Group Management | User creation, group management, sudo access and SSH restrictions |
| 02 | File & Directory Permissions | Ownership and permission management |
| 03 | Log File Analysis | Log analysis using Grep, AWK and Sed |
| 04 | Volume Management | Virtual disk, loop devices, ext4 and mounting |
| 05 | Process Management | Process monitoring and termination |
| 06 | Automated Backups | Bash scripting and cron scheduling |
